Vision & Principles

Vision
APF turns builders into founders by automating everything between “I shipped code” and “I’m earning revenue.”

Scoring System

Every project gets:

Market Demand, Competition, Build Effort, Support Burden, Distribution Fit, Revenue Potential.
Overall Productization Score (0-100).

APF CLI Tool Specification

Command: npx apf push [options]

Features:

Detects repo (git), zips relevant files (exclude node_modules, etc.).
Extracts README, package.json summary.
Uploads to APF cloud with metadata.
Triggers pipeline and sends mobile push.
Options:

--idea "description" for manual input.
--github-url for remote repo.
--dry-run for local validation.
Authentication: Via Supabase token or GitHub.

Output: Project ID + link to mobile workspace.

The AI Product Factory (APF) is now live. This prototype implements the "Productization Operating System" with a focus on the publisher mindset, validation-first workflows, and artifact-based intelligence.

Key Features Implemented:
The Golden Path: A complete flow from landing page to project creation and artifact generation.
Devil’s Advocate Agent: Dedicated UI for "kill or pivot" recommendations with a scoring system (0-100).
Artifact Dependency Graph: Visual status of the agent pipeline (Validation, Technical, Strategy, Pricing, Sales).
Feature-to-Benefit Translation: A component demonstrating the technical mapping of code features to market outcomes.
CLI Simulation: A terminal-style UI on the landing page showcasing the npx apf push developer experience.
Persistence: A Durable Object backend using SQLite to manage project state and agent artifacts.
Technical Stack:
Frontend: React 18 (via Babel), Tailwind CSS, Framer Motion, and Lucide Icons.
Backend: Hono on Cloudflare Durable Objects with SQLite storage.
Design: Modern dark-mode "SaaS" aesthetic with stone neutrals and primary blue accents.
